セキュリティ

セキュリティは有料オプションではありません

以下はすべて製品に含まれます。無料プランを含め、どのプランでも同じです。

堅牢な認証

ハッシュ化したパスワード（bcrypt）、複雑さのポリシー、連続失敗後のロック、復旧コード付き TOTP 二要素認証、セッションは個別にも一括にも失効できます。

封印された監査ログ

各エントリーは直前のエントリーの指紋を持ちます。一行を書き換える、あるいは途中の一行を抜く——それはその位置で鎖を断ち切ることであり、検証がどこかを告げます。できないこと：サーバーを握る者による書き換えの阻止。それを目に見えるようにするだけです。

個人データ

処理活動の記録、情報源ごとに書き出す開示請求対応、法が保存を求めるものは残しその旨を明示する削除。アカウントは削除ではなく匿名化され、参照している記録の整合性が保たれます。

内部通報窓口

フランスでは五十名以上で義務。内容はデータベース内で暗号化され、指名された担当者だけが読めます。管理者は読めません。通報が管理者を対象としうるからです。コードによる匿名の追跡が可能で、アカウントも記録も不要です。

検証されたバックアップ

毎時のアーカイブ、マニフェストによる完全性検査、データベースとファイルを戻す復元、FTPS または Google Drive への外部保管、失敗時には管理者へ通知。

暗号化された秘密情報

外部サービスのパスワード、API トークン、Webhook の秘密鍵。AES-256-GCM で暗号化され、二度と平文では表示されず、改ざんされれば読めなくなります。

自社サーバーでの運用も可

SaaS、または自社運用

SaaS では欧州でホスティングし、バックアップも含みます。有料プランではローカル運用も可能です。自社サーバーに導入すればデータベースは壁の外に出ず、更新は同じものが届きます。必要なのは一台だけ——Node 22 と SQLite、管理すべき外部データベースはありません。

できるとは言わないこと

電子署名は簡易なものであり、eIDAS の適格署名ではありません。金庫は文書を封印し日付を打ちますが、第三者に対抗できるタイムスタンプには認証局が必要です。税務・社会保険の電子申告は行いません。ソフトはデータを作り、提出は会計事務所の仕事のままです。契約後ではなく、ここに書いておきます。

よくある質問

データを自社サーバーに置けますか。
はい、有料プランで可能です。ソフトは Node 22 と SQLite により一台のマシンで動きます。データベースサーバーも外部サービスも不要です。データベース、書類、バックアップはお手元に残ります。
利用をやめたらどうなりますか。
管理コンソールから、インスタンス全体を書類ごと JSON で書き出せます。人質に取るものは何もありません。お客様のデータベースであり、読める形式で一緒に出ていきます。
社内ツールとの連携はどうですか。
スコープ付きの読み取り REST API と、署名付きの送信 Webhook はどのプランにも含まれます。人事システムや ERP、請求との個別連携はご相談ください。案件ごとにお見積もりします。

無料で始め、大きくなったらプランを変える

五名未満ならすべて無料です。それを超えると従業員ひとり月額 5 ユーロ（二百五十名から逓減）、あるいは買い切りライセンスなら一度きりの 10,000 ユーロ。試すのにカードは要りません。
