Ce que le logiciel est

Un CMS d'entreprise généraliste, pensé pour être acheté et exploité par une société qui veut piloter tous ses services depuis un seul endroit : direction, ressources humaines, finance, opérations, moyens généraux. Il n'est pas spécialisé dans un métier ; il couvre le tronc commun d'une entreprise et laisse aux outils spécialisés ce qui demande un agrément ou une certification.

Trois partis pris

Une donnée saisie une fois. Un congé approuvé apparaît dans l'agenda, bloque une planification de poste, alimente le solde et se retrouve dans les échéances. L'organigramme, l'annuaire et la recherche lisent le même rattachement. Rien n'est recopié d'un écran à l'autre.

Le refus plutôt que l'approximation. Une facture dans une devise dont le taux est inconnu n'est pas proposée ; un import contenant une ligne fautive n'est pas écrit du tout ; une non-conformité dont les actions sont en cours ne se clôture pas ; une écriture comptable déséquilibrée est rejetée en disant de combien. Une donnée fausse qui passe coûte plus cher qu'une saisie refusée.

Ce qui n'est pas couvert est écrit à l'écran. Chaque module affiche ses limites au moment de son activation, pas dans une note de bas de page : le moteur de paie applique les taux que vous saisissez et ne produit aucune DSN ; la facturation électronique génère le XML mais ne le dépose sur aucune plateforme ; la trésorerie ne se connecte à aucune banque.

Ce qu'il n'est pas

Certaines fonctions relèvent d'un tiers agréé et sont écartées volontairement plutôt qu'à moitié faites :

  • Télétransmission fiscale et sociale (DSN, TVA à la DGFiP) : demande un agrément, un format qui change chaque année et une responsabilité légale. Le logiciel produit les données, leur dépôt reste l'affaire d'un tiers déclarant.
  • Signature électronique qualifiée au sens eIDAS : demande un prestataire de confiance certifié. Le parapheur produit une signature simple, et l'attestation le dit elle-même.
  • Archivage à valeur probante (NF Z42-020, horodatage opposable) : demande une autorité de certification.
  • Édition collaborative de documents, visioconférence, téléphonie : chacun est un produit à lui seul.

Prise en main

npm install
npm start          # http://localhost:3000

Sur une instance vierge, toute l'application redirige vers l'assistant d'installation. Voir Installation pour le détail des cinq étapes, le déploiement automatisé et le jeu de données de démonstration.
