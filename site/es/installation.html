Instalación

Instalar Toutadmin

Dos ediciones del mismo producto: una funciona como servicio en su servidor, la otra se deposita en un alojamiento compartido. Ninguna base de datos exigida, ningún servicio de terceros — pero se usa un servidor MySQL si tiene uno. Cinco minutos para abrir el asistente y probar; una hora para una puesta en marcha completa, con servicio, HTTPS y copias de seguridad.

Solicitar mi instancia gratuita Descargar el producto

Alojada en Europa, nada que instalar: gratuita hasta cinco empleados, el producto entero desde el primer día. La abrimos a mano y le escribimos en cuanto esté lista.

La descarga está abierta a todo el mundo

La fórmula gratuita no se detiene en el SaaS: hasta cinco empleados puede igualmente instalar el producto en su propia máquina — sus ficheros, su base, sus copias de seguridad — sin pagar nada. Lo que decide la fórmula es la plantilla, no el lugar donde corre la instancia. A partir de cinco empleados hace falta una suscripción, tanto si la instancia corre en nuestra casa como en la suya.

Ver las fórmulas

Cuál instalar

La elección depende de su alojamiento, no de sus necesidades funcionales: ambas ediciones hacen exactamente lo mismo.

Edición Node

Para un servidor que usted administra: una máquina, un servicio permanente, un proxy inverso delante.

Node 22, un compilador de C, un disco local. Una máquina de un núcleo basta para unas decenas de personas. Se maneja un servidor MySQL si dispone de uno; si no, SQLite no pide nada.

Edición PHP

Para un alojamiento compartido: una carpeta que subir, un archivo que rellenar, una tarea programada. No hace falta línea de comandos.

PHP 8.1 y la extensión SQLite. Ninguna dependencia que instalar: ni Composer, ni gestor de paquetes. Y la extensión PDO MySQL si prefiere un servidor de base de datos.

La elección sigue siendo reversible

Ambas ediciones comparten el mismo esquema de base de datos y el mismo formato de contraseña. Pasar de una a otra es copiar un archivo de base y cinco carpetas: no hay conversión, y nadie tiene que cambiar de contraseña.

SQLite o MySQL

Y qué base de datos

La segunda elección, y la única que se cambia con dificultad. No depende de la edición: ambas aceptan los dos motores, y las cuatro combinaciones pasan las mismas pruebas.

SQLite

Un archivo en el disco del servidor. Nada que instalar, nada que administrar, nada que vigilar — y la instancia se muda copiando una carpeta.

Es el valor por defecto, y la respuesta correcta en la mayoría de los casos: un servidor de aplicación y un disco local que sobrevive de un despliegue a otro.

MySQL o MariaDB

Un servidor de base de datos, en la máquina o en otro punto de la red. Los datos viven donde su departamento de informática ya los respalda, replica y vigila.

Tómelo por tres razones: varios servidores de aplicación sobre una misma base, una política interna que lo impone, o un disco de aplicación efímero — un contenedor recreado en cada despliegue.

MySQL no es la elección de la velocidad

Es la creencia más extendida y es falsa: SQLite vive dentro del proceso, MySQL detrás de un socket. Medido aquí sobre dos mil operaciones, SQLite va de dos veces y media a ciento cincuenta veces más rápido según la operación — y aguanta la comparación incluso con ocho escritores simultáneos. MySQL se elige por dónde viven los datos y por quién los administra, no por el tiempo de respuesta.

El detalle, con las cifras

Tres caminos, un solo asistente

Poner el motor en marcha

Docker, un script de Linux, un script de Windows. Los tres se detienen en el mismo sitio: ante el asistente, en el navegador. Ninguno crea la base, la cuenta de administración ni la licencia — lo hace el asistente, en nueve pasos, y luego se cierra.

En contenedor

Una imagen por edición, un volumen para los datos. La instancia sigue siendo la misma tras cualquier cambio de imagen, licencia incluida.

docker compose up -d
# puis http://localhost:3000

En un servidor Linux

apt, dnf o apk. El script pone el motor, un usuario de sistema, un servicio que se reinicia solo, y el proxy inverso con su certificado si le da un dominio.

curl -fsSL https://repo.qu3ntin.com/toutadmin/toutadmin/-/raw/node/deploiement/install.sh \
  | sudo bash -s -- \
  --domaine intranet.exemple.fr \
  --courriel vous@exemple.fr

En Windows

Node se descarga como archivo comprimido, no como instalador: la versión queda fijada y no hace falta ningún compilador. Una tarea arranca con la máquina.

# PowerShell, en administrateur
powershell -NoProfile -ExecutionPolicy Bypass -Command \
  "& ([scriptblock]::Create((irm https://repo.qu3ntin.com/toutadmin/toutadmin/-/raw/node/deploiement/install.ps1))) -Port 3000"

Instalada por un script o una imagen, la instancia ya no se actualiza sola

Y es a propósito: los archivos reescritos dentro de un contenedor desaparecen al primer reemplazo — la actualización parecería funcionar y luego se deshaced sola. La pantalla «Actualizaciones» sigue avisando de las versiones, pero da el gesto en lugar del botón: cambiar de imagen, o relanzar el script.

Sistemas compatibles

Todos los sistemas que aún tienen soporte

Un script por familia de sistemas, un solo comando. Reconoce la máquina, instala lo que falta y se detiene ante el asistente.

Linux

Debian 11, 12, 13 · Ubuntu 22.04, 24.04, 26.04 · AlmaLinux 8, 9, 10 · Rocky Linux 8, 9, 10 · Red Hat Enterprise Linux 8, 9, 10 · CentOS Stream 9, 10 · Oracle Linux 8, 9, 10 · Amazon Linux 2023 · Fedora · openSUSE Leap 15, 16 · SUSE Linux Enterprise 15, 16 · Arch Linux · Alpine Linux

Windows

Windows 10 (1607+) · Windows 11 · Windows Server 2016 · Windows Server 2019 · Windows Server 2022 · Windows Server 2025

x86_64 y arm64. Si la distribución no ofrece Node 22, el script toma el archivo oficial de nodejs.org y comprueba su suma SHA-256 antes de extraerlo.

Windows 8.1 y Server 2012 R2 no son compatibles: Node 22 no arranca en ellos.

Para la rama de desarrollo: --dev en Linux, -Dev en Windows.

Para probar: cinco minutos

La instalación rápida

Lo justo para abrir el asistente. El detalle viene justo después, paso a paso, con lo que hace cada orden y por qué.

Edición Node

Tres órdenes en un servidor que usted administra. La última genera un testigo de instalación y arranca la instancia.

git clone -b node \
  https://repo.qu3ntin.com/toutadmin/toutadmin.git
cd toutadmin && npm ci --omit=dev
INSTALL_TOKEN=$(openssl rand -hex 16) \
NODE_ENV=production node src/server.js

Edición PHP

Ninguna línea de órdenes: una carpeta que depositar, un fichero que copiar, un permiso de escritura que abrir.

# 1. le code, ou l'archive (racine → public/)
git clone -b php \
  https://repo.qu3ntin.com/toutadmin/toutadmin.git
# 2. cp config.sample.php config.php
# 3. chmod 770 data/
# 4. ouvrir https://votre-domaine/install

Luego el asistente hace el resto

La instancia arranca vacía y se cierra sobre sí misma: mientras no esté instalada, toda dirección lleva al asistente, y una vez instalada el asistente desaparece para siempre.

  1. 1 IdiomaEl de la instancia, entre los dieciséis. Se cambia más tarde, y cada cual conserva el suyo.
  2. 2 RequisitosEl asistente comprueba lo que tiene bajo los pies: versión, permisos de escritura, base, carpetas. Lo que falta se nombra, no se adivina.
  3. 3 ActualizacionesEl asistente comprueba que no haya nada más reciente antes de instalar nada: empezar con una versión desfasada es un mal comienzo.
  4. 4 LicenciaLa clave de activación, que el asistente busca en su área de cliente, o la licencia gratuita obtenida en un clic. También puede seguir sin ella y activarla después.
  5. 5 Base de datosSQLite en un archivo, que no pide nada, o MySQL / MariaDB si dispone de uno. El asistente prueba la conexión antes de comprometerse con ella.
  6. 6 OrganizaciónEl nombre de la empresa y la cuota anual de vacaciones. Dos respuestas, modificables después.
  7. 7 SeccionesLas áreas de negocio que instala. Una sección no instalada no muestra nada; se añade más tarde con una casilla, y sus datos la esperan.
  8. 8 AdministradorLa primera cuenta. Doce caracteres como mínimo: es la única cuenta que puede crear otras.
  9. 9 InstalaciónEl resumen y luego la instalación en cuatro fases anunciadas en pantalla. El asistente se cierra definitivamente.

Ponga el testigo de instalación antes de abrir el puerto

Entre el primer arranque y su paso por el asistente, el primero en llegar crearía la cuenta de administración. INSTALL_TOKEN cierra esa ventana: sin él, el asistente se niega a abrirse.

Asistente de instalación
Edición Node

En su servidor, en cuatro pasos

  1. Obtener e instalar

    npm ci en lugar de npm install: instala exactamente lo que describe el archivo de bloqueo. En un servidor, una versión que se desplaza es una avería que nadie entiende.

    git clone -b node \
  https://repo.qu3ntin.com/toutadmin/toutadmin.git /var/www/toutadmin
cd /var/www/toutadmin
npm ci --omit=dev

  2. Configurar

    Todo se ajusta con variables de entorno, y ninguna es obligatoria. Ponga INSTALL_TOKEN antes de abrir el puerto: entre el primer arranque y su paso por el asistente, el primero en llegar crearía la cuenta de administración.

    cp .env.example .env
# PORT, NODE_ENV=production, INSTALL_TOKEN…

  3. Confiarlo al sistema

    Lanzado a mano, el producto se detiene al cerrar la terminal. El servicio se reinicia solo y solo tiene permiso de escritura en su carpeta de datos.

    sudo systemctl enable --now toutadmin
journalctl -u toutadmin -f

  4. Cifrar la conexión

    Nunca sirva el puerto de la aplicación directamente en internet. Detrás del proxy, la instancia pone ella misma las cabeceras de seguridad, incluida HSTS, y solo sobre una conexión ya cifrada.

    sudo certbot --nginx -d intranet.exemple.fr
Edición PHP

En alojamiento compartido, en cuatro pasos

  1. Subir los archivos

    Es el paso en el que se falla. Si el servidor sirve la carpeta entera, la base de datos queda descargable por cualquiera: cuentas, huellas de contraseñas y caja fuerte incluidas.

    git clone -b php \
  https://repo.qu3ntin.com/toutadmin/toutadmin.git /var/www/toutadmin
# ou l'archive ; la racine web pointe sur public/, pas sur le dossier

  2. Escribir la configuración

    Es el asistente quien escribe la configuración, y lo hace en último lugar: mientras el archivo no exista, una instalación interrumpida no ha dejado nada tras de sí. Pone allí una clave propia de la instancia, que sella las firmas y cifra los secretos en la base: guárdela con lo demás.

    cp config.sample.php config.php
php -r "echo bin2hex(random_bytes(32));"   # session_secret

  3. Abrir los permisos de escritura

    SQLite escribe archivos vecinos junto a la base: es la carpeta la que debe ser escribible, no solo el archivo. El resto del producto puede quedar en solo lectura.

    chmod 770 data/     # le dossier, pas seulement la base

  4. Programar el barrido

    Un sitio PHP solo vive durante una petición. La tarea programada cierra los contratos vencidos, emite las facturas recurrentes, envía los webhooks y crea las copias de seguridad.

    * * * * * /usr/bin/php /var/www/toutadmin/tools/cron.php

Antes de abrirlo a los compañeros

Una copia que sale del edificio

Haga una enseguida, mientras la base es pequeña, y configure el destino remoto. Un archivo que se queda en el servidor que protege no protege nada.

Una cuenta de prueba sin permisos

Entre con ella y dé una vuelta. Es la única forma de ver la herramienta como la verán sus compañeros, y la comprobación que más se salta.

Dos administradores, no uno

Si activa la doble autenticación y pierde a la vez el teléfono y los códigos de recuperación, solo otro administrador puede volver a abrirle la puerta. No hay puerta trasera.
